# Changelog

Notable changes are recorded here. The project currently distributes source from `main`; no tagged or packaged release has been published.

## Unreleased

### Added

- Initial Folio reader with paper and dark themes, adjustable typography, heading navigation, search, and a read-only source view.
- Markdown tables, task lists, code highlighting and copying, front matter, and local images.
- Native file opening, drag-and-drop, command-line paths, recent files, relative Markdown links, and live refresh.
- A4 PDF export through a native save dialog.
- Linux app-menu installation and removal scripts.
- Electron functional checks with isolated settings, formatting checks, Ubuntu CI, and dependency-update configuration.
- MIT licensing, contributor guidance, issue templates, security reporting, architecture documentation, and application screenshots.

### Current limits

- Linux is the only tested platform. Distribution is from source, with no packaged installers or auto-update mechanism.
- This is a reader, with no editing, math rendering, Mermaid diagrams, MDX execution, or plugin system.
